## 3D html game
HALL is a first person shooter built using only HTML and CSS, with no JavaScript. The 3D hall, and animated guards, is made from CSS 3D transforms. All the game logic runs on hidden radio buttons and checkboxes, selected with :checked, :actives.

* How it works:

Movement and turning: You can operate the game based on the button checks or by pressig the action key + displayed key to rotate or enter torch mode.
Shooting: click a guard to shoot them, with a muzzle flash and gun recoil. Each guard is a checkbox.

Win and lose: shoot all four guards in 75sec to win. A CSS counter(k) tracks kills.

Atmosphere: flickering lamps, a torch mode that dims the hall, a main menu, and a red alarm that booms(kinda) in the last 10 seconds.


Controls: Press to move, Numpad + Action key or press to turn, L + action key or press for torch mode, and click guards to shoot .

## Skybound

Skybound is a small adventure game made using HTML and CSS. Explore floating islands, collect the hidden crystal, and unlock the portal to reach the next level. In the Ancient Ruins,  collect the crystal, and reach the exit to complete the game.

## Tic-Tac-Toe

Tic-Tac-Toe is a small web game I built using HTML, CSS and JavaScript. It started with the classic tic-tac-toe idea, but I wanted to add a few extra features to make it more fun to play.

You can play against the computer on three difficulty levels: Easy, Medium and Unbeatable. The game also keeps track of your matches, shows your stats, and has achievements and an XP system where you earn points and level up as you play.

I added sound effects and a few animations too, along with a custom Forest Arcade design using dark green, cream and orange colours. Your progress is saved in the browser, so your stats and unlocked achievements can stay there between visits.


## Shards clicker

Shards clicker is a game built in google sheets using apps scripts. It's a regular clicker game with a twist. Score more, unlock workers, powerups and rank on the leaderboard.
